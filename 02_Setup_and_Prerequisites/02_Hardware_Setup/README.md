# Hardware Setup

## Development Board

This project uses the **NUCLEO-F401RE** development board based on the
**STM32F401RE** microcontroller.

### Board Specifications

- **Board:** NUCLEO-F401RE
- **Microcontroller:** STM32F401RE
- **Core:** ARM Cortex-M4
- **Maximum CPU Frequency:** 84 MHz
- **Flash Memory:** 512 KB
- **SRAM:** 96 KB
- **On-board Debugger/Programmer:** ST-LINK/V2-1
- **USB Interface:** USB Mini-B

---

## Hardware Required

The following hardware is required to get started:

- NUCLEO-F401RE development board
- USB cable
- Computer with STM32CubeIDE installed

---

## Connecting the Board

Connect the **NUCLEO-F401RE** to the computer using the USB connector
connected to the onboard **ST-LINK** interface.
